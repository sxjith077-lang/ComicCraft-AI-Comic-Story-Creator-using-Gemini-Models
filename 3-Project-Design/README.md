App Flow:

1. User opens ComicCraft.
2. User enters a story idea or prompt.
3. User selects the required comic creation option.
4. App sends the request to the Gemini Models.
5. Gemini generates the story, characters, dialogues, and comic scenes.
6. The generated comic content is displayed on the screen.

UI Design:

- Clean and simple layout with a story prompt input box.
- Clear buttons for generating stories and comic content.
- Comic story and generated panels are displayed clearly.
- Attractive comic-style interface.
- Responsive design that works on both phone and computer screens.

Design Tools Used:

- Google AI Studio (Build Mode) – For generating the UI and application layout.
- Gemini Models – For AI-powered comic story and content generation.

Project Name:

ComicCraft – AI Comic Story Creator using Gemini Models
